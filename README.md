# 코딩나우 도구 모음 (tool_web_mini_tools)

설치 없이 브라우저에서 바로 쓰는 무료 도구 모음. 모든 계산·변환은 클라이언트에서 완결되므로 별도 서버·빌드 도구 없이 정적 호스팅이 가능합니다.

## 구성

```
index.html                     ← 메인 (카드 + 접이식 도구 목록)
tools.js                       ← 도구 레지스트리(단일 소스). 도구 추가 시 여기만 수정
tools/
├─ age-calculator.html         ← 🎂 만 나이 계산기
├─ salary-calculator.html      ← 💰 연봉 실수령액 계산기 (2026년 기준)
├─ image-converter.html        ← 🖼️ 이미지 포맷 변환기 (PNG·JPEG·WebP)
├─ char-counter.html           ← 🔤 글자수 세기
└─ ladder-game.html            ← 🪜 사다리 게임 (사다리타기)
```

메인 페이지의 도구 카드와 "목록 열기/닫기" 접이식 목록은 모두 `tools.js`의 `TOOLS` 배열에서 렌더링됩니다. 새 도구를 추가하려면 도구 페이지를 `tools/`에 만들고 `TOOLS`에 항목 한 줄을 추가하면 됩니다.

## 도구별 요약

| 도구 | 설명 |
| --- | --- |
| 만 나이 계산기 | 생년월일·기준일로 만 나이, 다음 생일 D-day, 총 일수 계산. 윤년·2/29 출생 처리. |
| 연봉 실수령액 | 2026년 4대보험·근로소득공제·누진 소득세·자녀세액공제 근사. 연봉/월급 토글, 비과세·부양가족 반영. **참고용**(간이세액표와 완전히 일치하지 않음). |
| 이미지 포맷 변환기 | 드래그앤드롭으로 PNG·JPEG·WebP 변환, 품질·리사이즈 조절, 전후 용량 비교. 파일은 서버로 전송되지 않음. |
| 글자수 세기 | 공백 포함/제외 글자수, UTF-8 바이트, 단어·줄·문장·원고지(200자), 목표 진행률. 이모지 1자 처리. |
| 사다리 게임 | 최대 20명, 이름·도착지 직접 입력. 전체 동시·한명씩·선택(클릭) 출발, 사운드 효과 on/off, Canvas 애니메이션. |

## 디자인

- 다크 "앰버 CRT 터미널" 테마 (스캔라인 + 글로우)
- `JetBrains Mono` + `Gowun Dodum` (Google Fonts)
- 반응형: 데스크탑 2열 → 모바일 1열
- 각 도구 페이지는 CSS·JS 인라인으로 독립 실행 가능. 메인(`index.html`)만 도구 목록 렌더링을 위해 `tools.js`를 함께 로드

## 사용법

저장소를 클론한 뒤 `index.html`을 브라우저로 직접 열거나, 임의의 정적 서버에서 서빙합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```
